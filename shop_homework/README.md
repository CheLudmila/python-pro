# Навчальна система управління магазином

Потрібен Python 3, додаткові бібліотеки не потрібні.

Запуск з папки DevelopPython\python-pro:

```powershell
python shop_homework/shop.py
```

`store.txt` містить початкові товари та клієнтів у UTF-8. Поля розділяються
крапкою з комою, десятковий роздільник ціни — крапка. Порожні рядки та
коментарі, що починаються з `#`, пропускаються.

## Класи

- `Product`: назва, категорія та ціна; `change_price()` змінює ціну.
- `Inventory`: залишки товарів; `get_quantity()` повертає залишок,
  `change_quantity()` встановлює його, `remove_product()` списує товар.
- `Customer`: ім'я, пошта та власний список замовлень; `add_order()` додає замовлення.
- `Order`: список позицій і загальна сума; `add_product()` додає товар у вказаній
  кількості, `calculate_total()` перераховує та повертає суму.
- `Store`: об'єднує товари й клієнтів; `from_file()` створює магазин із TXT.

Кількість на складі зберігається в `Inventory`, а кількість у замовленні —
у його позиції. `Product` не містить залишків. Магазин має власний склад
`store.inventory`; замовлення створюється як `Order(store.inventory)`.
Формат TXT залишається тим самим: під час читання характеристики формують
`Product`, а кількість записується в `Inventory`. Для звернення до залишку
використовується той самий об'єкт товару зі списку `store.products`.

Додавання до замовлення одразу зменшує залишок. Придбати більше, ніж є
на складі, або вказати непозитивну кількість не можна. Ціна фіксується в
позиції замовлення: подальша зміна ціни товару не змінює стару суму.

У `main()` наведена демонстрація: завантаження магазину, купівля двох
одиниць першого товару першим клієнтом, виведення суми та залишку.
Керування доступне через методи класів; інтерактивного меню немає.
Зміни виконуються в пам'яті: TXT не перезаписується, після нового запуску
початковий стан завантажується знову.
