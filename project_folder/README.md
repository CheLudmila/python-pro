# Духовна спадщина

Невеликий навчальний Flask-додаток: чотири маршрути та п’ять HTML-шаблонів. Добірки духовних книг і храмів Києва.

## Запуск

Відкрийте термінал у папці `project_folder` та виконайте:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

Відкрийте http://127.0.0.1:5000 у браузері. Для зупинки натисніть `Ctrl+C` у терміналі.

## Структура

```text
project_folder/
```

## Маршрути

| URL | Призначення | Шаблон |
| --- | --- | --- |
| `/` | Головна сторінка з кількістю книг | `index.html` |
| `/books` | Назви духовних текстів, релігійні традиції та жанри | `items.html` |
| `/about` | Опис додатку | `about.html` |
| `/churches` | Храми Києва: описи, адреси та джерела | `churches.html` |

Усі сторінки успадковують `base.html` зі спільним меню та стилями.
Функція `render_template()` передає дані Python у шаблони Jinja.
У `items.html` цикл `for` формує картки книг, а `else` показує повідомлення для порожнього списку.

Щоб змінити добірку, відредагуйте список `books` у `app.py`.
Для добірки храмів відредагуйте список `churches` у тому ж файлі.
База даних та реєстрація не потрібні.

## Пошук і фотографії

На сторінці `/books` форма надсилає GET-параметр `q`, наприклад `/books?q=Коран`.
Пошук знаходить частину назви без урахування регістру та зайвих пробілів на початку й у кінці.
Порожній запит показує всі книги. Посилання «Скинути пошук» повертає повну добірку.

Картки книг і храмів містять зображення з Wikimedia Commons.
Під кожним зображенням зазначені джерело, авторство та ліцензія.
Зображення завантажуються із зовнішнього сайту й потребують інтернету.
Вони відображаються повністю, без обрізання; підписи книг уточнюють видання або рукопис.
